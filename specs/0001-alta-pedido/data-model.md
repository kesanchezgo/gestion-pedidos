# Data Model — 0001-alta-pedido (Fase 1)

## Entidades

### Pedido

| Campo | Tipo | Restricción | Origen |
|---|---|---|---|
| `id` | BIGINT | PK, generado por BD (IDENTITY) | BD |
| `cliente_nombre` | VARCHAR(120) | NOT NULL | request |
| `cliente_email` | VARCHAR(254) | NOT NULL, formato email | request |
| `estado` | VARCHAR(20) | NOT NULL, valor fijo `ABIERTO` en v1 | app |
| `total` | NUMERIC(12,2) | NOT NULL, calculado en servidor | calculado |
| `creado_en` | TIMESTAMP | NOT NULL, default `now()` | BD |

### LineaPedido

| Campo | Tipo | Restricción | Origen |
|---|---|---|---|
| `id` | BIGINT | PK, IDENTITY | BD |
| `pedido_id` | BIGINT | FK → `pedidos.id` ON DELETE CASCADE, NOT NULL | rel |
| `descripcion` | VARCHAR(200) | NOT NULL | request |
| `cantidad` | INTEGER | NOT NULL, ≥ 1 | request |
| `precio_unitario` | NUMERIC(12,2) | NOT NULL, > 0, máx 2 decimales | request |

**Relación**: Pedido 1..* LineaPedido (`lineas`), cascade ALL + orphanRemoval; una línea no existe sin su pedido.

**Invariantes (server-side)**:

- `total = SUM(cantidad × precio_unitario)` con escala 2 y `HALF_UP` — recalculado en cada alta; el `total` del request se ignora.
- Un pedido nace con **≥ 1 línea** (`@NotEmpty`); sin líneas → 400.
- Sin transiciones de estado en v1 (nace `ABIERTO` y ahí queda).

## Esquema (dibujo de la migración V1)

```sql
CREATE TABLE pedidos (
    id              BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    cliente_nombre  VARCHAR(120)  NOT NULL,
    cliente_email   VARCHAR(254)  NOT NULL,
    estado          VARCHAR(20)   NOT NULL DEFAULT 'ABIERTO',
    total           NUMERIC(12,2) NOT NULL,
    creado_en       TIMESTAMP     NOT NULL DEFAULT now()
);

CREATE TABLE lineas_pedido (
    id               BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    pedido_id        BIGINT        NOT NULL REFERENCES pedidos(id) ON DELETE CASCADE,
    descripcion      VARCHAR(200)  NOT NULL,
    cantidad         INTEGER       NOT NULL CHECK (cantidad >= 1),
    precio_unitario  NUMERIC(12,2) NOT NULL CHECK (precio_unitario > 0)
);

CREATE INDEX ix_lineas_pedido_pedido_id ON lineas_pedido (pedido_id);
CREATE INDEX ix_pedidos_creado_en ON pedidos (creado_en DESC);
```

## Mapeo JPA (resumen)

```
Pedido ──< LineaPedido          (@OneToMany(mappedBy="pedido", cascade=ALL, orphanRemoval=true))
PedidoRepository extends JpaRepository<Pedido, Long>
  - findByIdOrThrow → servicio lanza PedidoNotFoundException → 404
Page<Pedido> findAll(Pageable sorted createdAt desc)
```
